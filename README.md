# 🚀 Personal Portfolio Website

Welcome to my personal portfolio repository! This is a modern, responsive, and animated multi-page website designed to showcase my web development skills, projects, and professional background.

## ✨ Features
- **Modern UI/UX:** A sleek dark theme complemented by vibrant neon blue accents and elegant glassmorphism styling.
- **Fully Responsive:** Adapts seamlessly to provide a great viewing experience across desktops, tablets, and mobile devices.
- **Dynamic Animations:** Features engaging typing effects, smooth hover transitions, and interactive UI cards.
- **Multi-page Structure:** Cleanly separated pages for `Home`, `About`, `Skills`, `Projects`, and `Contact` for easy navigation.

## 🛠️ Technologies Used
- **HTML5:** Clean, semantic markup structuring the content.
- **CSS3:** Custom styling utilizing Flexbox/Grid, CSS variables, and modern visual effects.
- **Vanilla JavaScript:** DOM manipulation and logic for dynamic features (e.g., the typing text effect).
- **FontAwesome:** Scalable vector icons for social links and technical skill badges.

## 📂 Project Structure
```text
├── index.html       # Landing page featuring the hero section
├── about.html       # Detailed background and professional services
├── skills.html      # Visual grid of technical skills and tools
├── projects.html    # Showcase of recent work (e.g., BiSync)
├── contact.html     # Contact information and social links
├── style.css        # Global stylesheet and design system
└── script.js        # Interactivity and dynamic animations.
```
